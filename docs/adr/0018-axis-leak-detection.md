# ADR-0018: 軸名の漏れは抑え込まず、検出して数える

- 状態: **採用**
- 日付: 2026-08-20
- 関連: [ADR-0012](0012-stat-section-directive.md) の「測り直し — 12条件 × 2群」

## 背景

**性格ステータスの軸名が地の文に漏れる**（[ADR-0012](0012-stat-section-directive.md) の (A)）。

> （コーヒーを淹れながら、笑顔で話しかけてくる。**ユーモアたっぷりな口調**だが、**共感**も込めているようだ。）

面白く喋るのではなく「面白く喋った」と描写する形で、**値の大小が文体ではなく
書かれるラベルの内容だけを変える。**

**定数行の言い回しで抑え込む方針は、裏付けが無い。**
2026-08-20 の測り直しで、本番のプロンプトで **2/12**、
分割前の合成した1行に戻した対照群でも **1/12** 起きた。
**数字と条件は ADR-0012 が正。ここに写さない。**

## 決定

**抑え込みを試す前に、検出して数える。**

- **プロンプトに実際に載った軸名**が、応答の**地の文**に現れたら記録する。
- **台詞に現れた場合も記録する。** `STAT_AXIS_DIRECTIVE` は
  「項目名や数値に触れない」であって地の文に限定していない。**ただし別の欄で数える**
  （地の文の方が (A) の本体で、台詞内は違う壊れ方）。
- **記録だけ。応答には一切影響させない。** 落とさない・書き換えない・エラーにしない。

### 数値は検出しない

「項目名や**数値**に触れない」の後半は**判定できない。**
`5` という数字が性格値の漏れなのか「5分待って」なのかを、出力から決める方法が無い。
**できないことを見張るふりをしない。**

### プロンプトに載らなかった軸は見ない

**値 0 の軸はプロンプトから落ちている**（CLAUDE.md 絶対制約）ので、
モデルはその軸名を読んでいない。にもかかわらず一致したなら、
それは**たまたま同じ語が出た**だけである。**判定の対象から外す。**

## 理由

### なぜ抑え込みではなく検出か

- **抑え込みが効くという根拠が無い。** 2つの文面で測って、どちらも消えていない。
  **効くかどうか分からない対策を入れると、入れたこと自体が「対処済み」として記録に残る。**
- **検出は安い。** 文字列の照合だけで、外部通信も追加の LLM 呼び出しも要らない。
- **率が見えるようになる。** いま「1割弱、ユーモアが高い個体に偏る」と言えるのは
  **手で12条件を測ったから**で、本番では誰も数えていない。
  プロンプトを触るたびに手で測り直すのは続かない。
- **次の判断材料になる。** 抑え込みを試すにしても、受け入れるにしても、
  **率が動いたことを観測できる形が先に要る。**

### 却下した選択肢

- **言い回しをさらに強める** — 2つの文面で消えていない。**強めた文面で測ってから決める話**で、
  いま入れると「対処した」という記録だけが残る。予算も 10 バイトしか無い。
- **後処理で削る／書き換える** — **地の文を壊す。**
  「ユーモアたっぷりな口調だが」から軸名だけ抜くと文が成立しない。
  文ごと落とすと応答の意味が変わる。**LLM の出力を黙って書き換えない。**
- **黙って受け入れる** — 率が動いても誰も気づかない。
  **プロンプトを触った作業単位が悪化させても分からない。**
- **エラーにする／再生成する** — 1割弱で失敗する会話基盤になる。**利用者から見て壊れている。**

## 結果

### 得られるもの

- **本番の発生率が、プロンプトを触るたびに手で測らなくても見える。**
- **地の文と台詞を分けて数えられる**ので、壊れ方の内訳が残る。

### 諦めたもの / 前提

- **誤検出は受け入れる。** 「共感」という軸名を持つキャラクターで
  「共感してくれてありがとう」と台詞に出れば1件と数える。
  **これは門ではなくログ**なので、誤検出の代償は雑音だけである。
  短い軸名（1〜2文字）ほど誤検出しやすい。
- **見逃しも受け入れる。** 「面白い口調で」のように**軸名を使わずに同じ欠陥**が起きる形は捕まえられない。
  **数えているのは「軸名の一致」であって「(A) そのもの」ではない。**
  率を比べる用途には足りるが、**0 件を「起きていない」と読まないこと。**
- **判定は純粋関数に置く。** 応答の生成経路に I/O を足さない。
