## 書き方

1ファイル1決定。以下の構成で簡潔に。

```markdown
# ADR-NNNN: タイトル

- 状態: 採用 / 未決 / 却下 / 置換（ADR-MMMM による）
- 日付: YYYY-MM-DD

## 背景
何に困っていたか。

## 決定
何を決めたか。

## 理由
なぜそれを選んだか。**却下した選択肢とその理由も書く。**

## 結果
これによって何が可能になり、何を諦めたか。
```

**却下した選択肢を書き残すことが最も重要。** それがないと、後から同じ議論を繰り返す。
状態が変わったら追記し、古い記述は消さずに残す。
