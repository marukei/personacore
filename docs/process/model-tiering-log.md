# サブエージェントの階層と、定型階層の A/B 記録

2026-09-23 に司令塔が Fable 5.1 → Opus 5.5 へ移ったとき、サブエージェントを階層に割り直した。
**モデルとエフォートの権威は各定義の frontmatter**（`.claude/agents/*.md`）。下の表はどれを使うかの案内で、値を写したものではない。

## 階層

| 階層 | 用途 | 定義 |
|---|---|---|
| 設計 | 設計判断、曖昧さの大きい実装、複数ファイルにまたがる変更 | `rust-implementer-design` |
| 標準実装 | 仕様が明確な実装 | `rust-implementer` |
| レビュー | コードレビュー（読み取り専用） | `rust-reviewer`（汎用は `~/.claude/agents/code-reviewer`） |
| 定型 | リネーム、横展開、ボイラープレート、単純なテスト修正 | `rust-routine-opus` / `rust-routine-sonnet` を**交互に**使い、下の表に記録する |
| 探索・集約 | コード探索、テスト実行、ログ要約 | `personacore-explorer` |
| エスカレーション | 上の階層で解けない難所 | `rust-implementer-escalation` |

- **エスカレーションは、使う前に理由を利用者へ報告して承認を得る。** 使ってよいのは
  「設計階層で2回試行しても解決しない」か「正解の定まらない問い（アーキテクチャ選定・根本原因が不明な調査）」のときだけ。
- **Agent ツールの呼び出しで `model` を渡さないこと。** 呼び出し側の `model` は frontmatter より優先され、階層が黙って崩れる。
- **環境変数 `CLAUDE_CODE_EFFORT_LEVEL` が立つと、frontmatter の `effort` はすべて無効になる**（2026-09-23 時点では未設定）。
- **作業者系の5つ（`rust-implementer*` / `rust-routine-*`）は本文が同一**（frontmatter だけが違う）。本文を直すときは5つとも直すこと。同一性を見張る仕掛けはまだ無い（origin#26）。
- **自己申告の実測**（2026-09-23 / アプリ再起動後）: Opus の4定義は `claude-opus-5-5[1m]`、Sonnet の2定義は `claude-sonnet-5`、エスカレーションは `claude-fable-5-1`。
  `[1m]` は 100万トークンの文脈版で、モデルは一致している。
- **エフォートは自己申告できないが、サブエージェントの会話ログに残っている。**
  `~/.claude/projects/<project-dir>/<セッションID>/subagents/agent-<id>.jsonl` の `"effort"` の欄を読む
  （`Select-String -Pattern '"effort":"[a-z]+"'`。**ファイルは数百 KB あるので丸ごと読まない**）。
  2026-09-23 に8定義とも frontmatter と一致した（`rust-routine-opus` は `low`）。
- **⚠ 定義の書き換えは、実行中のセッションには効かない。** 再起動前に呼んだ既存の3定義は、
  **effort が `high`（親セッションの値）で、モデルは `[1m]` なし**と記録されていた ——
  **書き換える前の定義（`model: opus`・effort 未指定）で動いていた。** 新しい定義ファイルも再起動まで一覧に出ない。
  **frontmatter を変えたら、アプリを再起動してから上の方法で確かめること。**

## 2026-09-29: Sonnet 5 → Sonnet 5.5

利用者の依頼で、Sonnet 5 を使っていた2定義を **Sonnet 5.5（`claude-sonnet-5-5`）** に替えた。値の出どころは `claude-api` スキルのモデル表（2026-09-25 時点のキャッシュ）。

| 定義 | 前 | 後 | 理由 |
|---|---|---|---|
| `personacore-explorer` | `claude-sonnet-5` / medium | `claude-sonnet-5-5` / medium | 読み取り専用の探索。エフォートはそのまま |
| `rust-routine-sonnet` | `claude-sonnet-5` / high | `claude-sonnet-5-5` / **medium** | Sonnet 5.5 はエフォートの段階が調整し直され、「エージェントのコーディングと多段のツール使用は medium から始めて測り直す」とされている（`claude-api` スキル）。**高すぎる側から始めない** |

- **Opus 5.5 の4定義（設計・標準実装・レビュー・定型 A）は動かさない。** 価格は Sonnet 5.5 が Opus 5.5 の半分（入力 $2 / 出力 $10 対 $4 / $20、100万トークンあたり）だが、レビュアーは毎回テストの穴を実際に見つけており、軽くする実測が無い。**「Sonnet 5.5 で足りる」と言えるのは、下の A/B と探索役の使用で数が溜まってから。**
- **定型の A/B は B 側のモデルが替わったので、ここから数え直す**（下の表の 2026-09-27 の Sonnet 5 の行は旧モデルの記録）。
- エフォートの既定は Sonnet 5.5 が `high`、Opus 5.5 が `medium`。**frontmatter に `effort` を必ず書く**（書かないと既定が効き、モデルごとに違う）。
- **⚠ 効くのはアプリを再起動してから**（上の「定義の書き換えは、実行中のセッションには効かない」）。再起動後に自己申告のモデル ID と会話ログの `"effort"` で確かめる。
  → **2026-09-29 に再起動後に確かめた**: `personacore-explorer` と `rust-routine-sonnet` の両方が自己申告 `claude-sonnet-5-5`、会話ログの `"effort":"medium"`・`"model":"claude-sonnet-5-5"`。
