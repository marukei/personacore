# ADR-0045: 変容の走らせ方をキャラクターごとに持ち、画面から切り替える

- 状態: **採用**（2026-09-26 / 利用者が「変容の走らせ方を GUI からコントロール出来ない」と指摘し、単位は「キャラクターごと」を選んだ。細部は司令塔）
- 日付: 2026-09-26
- 関連: [ADR-0024](0024-stat-drift.md) §8（**既定は off、環境変数で切り替える** —— この ADR が単位を変える）/

## 背景

変容は `PERSONACORE_STAT_DRIFT`（既定 off）でしか動かせない。**配布物の利用者は環境変数を立てて exe を起こす形を知らないので、
変容は事実上いつも止まっている。** 画面は「いまは停止しています」と言う（D-5a）が、動かす手段を画面の外にしか持たない。

ADR-0024 §8 が既定を off にした理由は**測定**である —— on のままだと、抽出の質を測っている最中に性格が動き、
同じ会話を2回投げて比べる測定が成立しない。**この理由は「測る会話」についてのもので、遊ぶ会話には当たらない。**
測る会話と遊ぶ会話はキャラクターで分かれる（測定の台本はキャラクターを新しく作る）。

## 決定

1. **キャラクターが自分の走らせ方を持つ。** 値は `off` / `shadow` / `on` のどれか、または**未設定**。
   **未設定は「起動時の既定（`PERSONACORE_STAT_DRIFT`。無ければ off）に従う」。**
   **既存のキャラクターは全部未設定から始まる**ので、この変更を入れても、いまの DB の振る舞いは1つも変わらない。
2. **効く走らせ方は「キャラクターの値があればそれ、無ければ起動時の既定」。** 変容を走らせる度（ターンごと）に決めるので、
   **切り替えは次のターンから効く。起こし直しは要らない。**
3. **書く口は既存の `PATCH /admin/characters/{handle}`**（と作成の `POST`）の欄 `stat_drift_mode` を1つ足すだけ。
   `"off"` / `"shadow"` / `"on"` で設定、`null` で未設定へ戻す、欄を省けば変えない（`output_format_instruction` と同じ3状態）。
   **受け付ける綴りはこの3つだけ**（環境変数が受ける `0` / `true` / `yes` 等の別名は受けない —— 画面が送るのは正の綴りだけで、別名を受けると保存された値の綴りが割れる）。
4. **読む口は変容の応答（`GET .../drift`）に足す。** いまの `run_mode`（**効いている走らせ方**）の隣に、
   **どこから来たか**（キャラクターの値か、起動時の既定か）と、**起動時の既定そのもの**を載せる。
   画面が「既定に従う（いまは停止）」と言えるように。
5. **画面に出すのは走らせ方だけ。** 依頼の形（`PERSONACORE_DRIFT_FORM`）・注記（`PERSONACORE_DRIFT_NOTE`）・
   `λ` / 傾き / 1歩の費用は**環境変数のまま**。前の2つは**測定の器具**で機能の設定ではなく（`config.rs` の doc）、
   後の3つは ADR-0036 §決定3 の「つまみを増やさない」に当たる。
6. **切り替えは、積み上がったもの（累積・票・値）に触らない。** off にすると判定が走らないだけで、on に戻すと続きから動く。
   off の間は累積も積まれない（ADR-0026 のまま）。

## 却下した選択肢

- **全体で1つの設定を画面に置く**（保存先のファイルに覚える。`selected-upstream.txt` と同じ形）——
  作業は小さいが、**遊ぶキャラと測るキャラを分けられない**。ADR-0024 §8 の理由（測定）を守るには、
  遊ぶ間は全体を on、測る間は全体を off と切り替え続けることになり、切り替え忘れがそのまま測定を壊す。利用者が退けた。
- **起動時の既定を捨て、キャラクターの値だけにする** —— 測定の台本と `tests/` の変容の見張り番は環境変数で走らせ方を決めている。
  捨てると全部を書き直すことになり、得るものが無い。**未設定＝既定に従う**で両立する。
- **環境変数がキャラクターの値に勝つ** —— 画面で「動かす」にしたのに動かない、が起きる。画面で選んだものが効く形にする。
  測定は新しく作ったキャラクター（未設定）で走るので、環境変数はそのまま効く。
- **依頼の形・注記・`λ` 等も画面に出す** —— 上の決定5。

## 結果

- 配布物の利用者が、画面だけで変容を動かせる。
- **⚠ 既存のキャラクターに値を書いた測定は、環境変数に従わなくなる。** 測定を既存のキャラクターで回すなら、先にその値を未設定へ戻すこと。
  変容を走らせるログに「効いた走らせ方とその出どころ」を載せ、取り違えを後から追えるようにする。
