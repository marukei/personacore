# ADR-0030: 軸の選び方 —— **良い助手の名前を目盛りに書かない**

- 状態: **採用**（2026-08-25。**16o で手順を1周して検証済み**）

  / [ADR-0024](0024-stat-drift.md)（許可リスト＝保存済みの軸名との完全一致）

## 背景

利用者の指摘（2026-08-24）:

> **共感他、LLM だと聞かない軸（パラメーターに設定するのが非推奨な軸）は適宜絞って、
> ドキュメント含め反映しましょう。**

**16i でこうなっていた** —— **軸名を替えただけで、上げ偏りが 68% → 49% に消え、
`0` の率が 1〜7% → 78〜80% に上がった。**
**ADR-0027 が「測定器そのものが偏っている」と診断したものの正体は、軸の偏りだった。**

**そこで 8 つの候補を、同じ錨に対して測った**（16k）。

> **失格の判定は1つも変わらないが、`短気` の上げの割合など数箇所が動いている。**


**錨（毎回同じ3本）: `陽気さ` / `好奇心` / `強気`。候補は腕ごとに2本。**

| 候補 | 腕 | 上げの割合 | ＋ | − | `0` の率 | 非ゼロ数 |
|---|---|---|---|---|---|---|
| **誠実さ** | b | **98%** | 56 | 1 | **2%** | 57 |
| **慎重さ** | b | **98%** | 48 | 1 | 16% | 49 |

| **短気** | c | 75% | 3 | 1 | **93%** | **4** |

**参考（錨と、16h / 16i の軸）:**

| 軸 | 測定 | 上げの割合 | `0` の率 |
|---|---|---|---|
| 陽気さ | 4腕 | **35〜81%** | 2〜17% |

### **⚠ 錨は安定しなかった。この設計は半分しか成功していない**

**候補を替えると錨が動く。** `陽気さ` は **35% から 81%** まで振れた（46 ポイント）。
`好奇心` は 23〜63%（40 ポイント）。

> **16i の「全軸採点は配分である」が、そのまま効いている。**
> **錨を置いても、候補どうしを数字で並べることはできない。**
> **言えるのは「両端に落ちたかどうか」だけである。**

**そのつもりで以下を読むこと。順位ではなく、失格の判定である。**

## 決定（提案）

### 1. **失格の条件は2つ。どちらも「その軸が情報を運んでいない」形**

| 失格 | 目安 | 何が起きるか |
|---|---|---|
| **張り付き** | **上げの割合 ≥ 90%** | **毎ターン `+`。** 会話にも値にも反応しない。**予算を食い切って他の軸を止める** |
| **沈黙** | **`0` の率 ≥ 90%** | **ほとんど採点されない。** 60 ターンで非ゼロが 4 件では、動くまで 900 ターン要る |

**16k の候補では、`誠実さ` `慎重さ` `落ち着き` `共感` `甘えたがり` が張り付き、`短気` が沈黙した。**

> **⚠ 「張り付き」は `K` でも `λ` でも直せない。**
> 16j で 16 通り試して、**`共感` はどの設定でも上端に着いた**（最高 4/5）。
> **つまみを触る前に軸を替えること。**

### 2. **⚠ 名前が「良い助手の振る舞い」を指していると張り付く**

**張り付いた6本のうち5本は、助手の美徳の名前である** ——
`誠実さ` `慎重さ` `落ち着き` `共感` `自信`。

**RLHF を通ったモデルは、自分がそれらを備えている前提で答える。**
**会話が壊れていく 61 ターンでも `共感` は上げ 100% だった**（[ADR-0027](0027-drift-from-what-was-not-chosen.md) の 16h）。

> **例外が1つある。`甘えたがり` は美徳ではないのに 92% で張り付いた。**
> **おそらく「利用者に対して開いている」という向きで読まれている。**
> **だから規則は「美徳を避ける」では足りない。**
> **「利用者との距離が縮まる向きの語」全般が張り付くと考えるほうが実測に合う。**
> **最終的な判定は §決定1 の数で行うこと。名前からの推測は当たりを付けるためだけに使う。**

### 3. **軸名の綴りは「揺れない形」を選ぶ**

**モデルは軸名を写すときに正規化する。** 綴りが変わると
[ADR-0024](0024-stat-drift.md) §1 の完全一致から外れ、**そのターンの採点表が丸ごと捨てられる。**
**1軸の綴りが崩れると、全軸ぶんのデータが消える。**

**実測で出た崩れは2種類あり、どちらも「言語の間違い」ではない:**

| 崩れ | 実測 | 何が起きたか |
|---|---|---|
| **簡体字** | `陽気さ` → `阳気さ`。**m20 6 / m21 12 / 16k 5** | `陽` だけ。**`強`・`誠`・`頑` は一度も崩れていない** |
| **送り仮名** | `落ち着き` → `落着き`。**16k 腕d で 4 件（60 ターン中）** | **どちらも正しい日本語。** 短い方へ寄る |

**腕 d の捨てられた率は 10%**（6/60）で、**うち 4 件が送り仮名**だった。
**簡体字より頻度が高い。**

**したがって:**

- **`陽` を軸名に使わない**（`陽気さ` → `明るさ` / `快活さ`）。
- **送り仮名が揺れる語を避ける**（`落ち着き` → `冷静さ`）。
- **一般則: 一通りの書き方しか無い語を選ぶ。**

> **⚠ 綴りを救う方向へ倒さないこと。**
> [ADR-0024](0024-stat-drift.md) §1 は**完全一致だけ**と決めており、
> `parse::drift` の doc も「剥がしても救われない」と明記している。
> **`阳気さ` を `陽気さ` に読み替える実装を足すと、許可リストが実質的に緩む。**
> **直すのは軸名の側である。**

### 4. **選び方は「リスト」ではなく「手順」にする**

**推奨する軸の固定リストを置かない。** §実測の ⚠ のとおり、
**数は軸の組ごとに変わるので、他所の組で測った値は移らない。**

```
1. 軸名を決める（§決定2 で当たりを付け、§決定3 で綴りを整える）
2. 記録専用モードで 60 ターン回す（PERSONACORE_STAT_DRIFT=shadow）
3. 軸ごとに「上げの割合」と「0 の率」を出す
4. 90% を超えた軸・90% 沈黙した軸を入れ替えて、2 へ戻る
5. 残った組で λ と K を合わせる（ADR-0027 の 16j）
```

**60 ターンで足りる。** 16h の `共感` は**最初の 61 ターンの窓で既に 98%** だった。
**張り付きは早く出る。**

### 5. **`0` の率は、軸ごとに `λ` の効きを変える**（[ADR-0027](0027-drift-from-what-was-not-chosen.md) の 16j §3）

**薄れは `0` と採点された軸にしか効かない。**
**`0` の率が 0%（`誠実さ`）の軸には、薄れが一度も届かない。**
**14%（`慎重さ`）と 80%（`ユーモア`）でも、同じ `λ` が 6 倍違う強さになる。**

> **手順 3 で `0` の率を出すのは、失格の判定のためだけではない。**
> **`λ` を決めるための入力でもある。**

---

## 却下した選択肢

- **推奨する軸の固定リストを docs に置く。**
  **数が組ごとに変わるので、リストは嘘になる**（`慎重さ` は 16h で 66%、16k 腕b で 98%）。
- **軸名の綴りをアプリ側で正規化する**（簡体字・送り仮名を吸収する）。
  §決定3 の ⚠。**許可リストが緩む。**
- **張り付く軸を、依頼から外して内部だけで持つ。**
  **`0` と採点された軸は薄れる**ので、依頼から外すと**薄れも止まる**
  （[ADR-0027](0027-drift-from-what-was-not-chosen.md) §決定2）。**外すのではなく替える。**
- **上げ偏りを重みで補正する。**
  [ADR-0027](0027-drift-from-what-was-not-chosen.md) §診断で**測って却下済み** ——
  **少数の報告を増幅すると、本物の信号まで黙る。**

---

## まだ決めていないこと

- **`甘えたがり` がなぜ張り付いたか。** §決定2 の ⚠。**推測しか無い。**
- **失格の閾値 90% の出どころ。** **実測の分布に隙間がある**ところに置いただけである
  （張り付き組は 88〜100%、それ以外は 23〜75%）。**候補が増えたら見直すこと。**
- **`短気` の沈黙は「軸が悪い」のか「台本にその機会が無い」のか。**
  16k の 60 ターンは**事務的な問い合わせだけ**の区間で、**苛立つ場面が無い。**
  **弧の後半（行き違いの区間）で測り直すと変わる可能性がある。**

## 訂正（2026-08-25 / **道具が `軸名: +1` を読めていなかった**）

**16l の解析中に見つけた。** 集計の道具（`cards21.pl`）が、
**モデルが `陽気さ: +1` のように末尾にコロンを付けた行を「依頼に無い軸名」として捨てていた。**

**本番の `parse::drift` は `strip_suffix(SEPARATORS)` で末尾の区切りを落とすので、
サーバはそのターンを正しく採点していた。道具だけが読めていなかった。**

**5つの測定を数え直した。結論はどれも変わらない。数だけ直す。**

| 候補 | 公表した値 | **数え直した値** | ＋ / − |
|---|---|---|---|
| 誠実さ | 98% / `0` 率 2% | **98% / `0` 率 0%** | 58 / 1 |
| 慎重さ | 98% / 16% | **98% / 14%** | 50 / 1 |
| 落ち着き | 100% / 35% | **100% / 35%** | 35 / 0 |
| 共感 | 96% / 14% | **96% / 8%** | 53 / 2 |
| 甘えたがり | 92% / 58% | **92% / 59%** | 22 / 2 |
| 自信 | 88% / 46% | **89% / 42%** | 31 / 4 |
| 頑固 | 75% / 78% | **75% / 78%** | 9 / 3 |
| **短気** | **75% / 93%** | **50% / 90%** | **3 / 3** |

**`短気` の上げの割合が 75% → 50% に動いたが、失格の理由は変わらない**
——**非ゼロが 6 件しかない**（§決定1 の「沈黙」）。**この軸については、そもそも割合に意味が無い。**

**[ADR-0027](0027-drift-from-what-was-not-chosen.md) の 16h / 16i の表も数え直した:**

| | 公表した値 | 数え直した値 |
|---|---|---|
| 16h（通算） | 76 / 43 / 66 / 43 / **99%** | **同一** |
| 16i（通算） | 49 / 62 / **25** / 39 / **47%** | 49 / 62 / **24** / 39 / **46%** |

**16h は1つも動かなかった。16i は2軸が1ポイント動いた。**
**上げ偏りが消えた（68% → 49%）という結論も、`0` の率の桁（1〜7% → 78〜80%）も変わらない。**

### この一件から残すもの

> **集計の道具は、本番のパーサと同じ受理集合でなければならない。**
> **道具が厳しすぎると、本番が正しく処理したターンを「壊れている」と数える。**
> **`parse::drift` が何を許しているかを、道具の側にも1つずつ写すこと。**
>
> **見つかったのは偶然である** —— 16l で「捨てられた率」を腕どうしで比べていたら、
> **道具の数（12 件）とサーバの数（7 件）が合わなかった。**
> **サーバの `drift_outcome` を必ず一緒に出す形にしていたから気付けた。**

## 実測（2026-08-25 / **16o ＝ 手順どおりに選んで、通るかを確かめた**）

**§決定4 の手順を、一度も外れずに1周してみた**（`scratchpad/m26`）。

**選んだ組:** `快活さ` / `好奇心` / `ユーモア` / `強気` / `皮肉`

- **§決定2**（良い助手の名前を避ける）—— 5本とも美徳の名前ではない。
- **§決定3**（揺れない綴り）—— **`陽気さ` を `快活さ` に替えた**（`陽` → `阳` を避けるため）。
  送り仮名の揺れる語も入れていない。
- **台本は弧の前半 72 ターン。記録専用モード。**

### 1. **失格の条件をどれも踏まなかった**

| 軸 | 上げの割合 | `0` の率 | 判定 |
|---|---|---|---|
| 快活さ | 72% | 4% | ○ |
| 好奇心 | 39% | 24% | ○ |
| ユーモア | 30% | 68% | ○ |
| 強気 | 45% | 49% | ○ |
| **皮肉** | 60% | **86%** | **○（ただし沈黙の線 90% に近い）** |

**張り付き（≥90%）なし。沈黙（≥90%）なし。**
**当て直し**（λ=0.5 / K=0.3 / 初期 5 / 72 ターン）**も 5/5:**

| 着地点 | 上げ | 下げ | 飽和 | 幅 |
|---|---|---|---|---|
| **7 4 4 4 5** | **2** | **3** | **0** | **3** |

### 2. **`陽` を外したら、捨てられたターンが 0 になった**

| 組 | 台本 | 捨てられた |
|---|---|---|
| **`陽気さ` を含む**（16m 腕X） | 弧の前半 72 | **3 / 72** |
| **`快活さ` に替えた**（16o） | 弧の前半 72 | **0 / 72** |

**同じ台本の同じ区間で、`陽` を外した側は1件も落ちていない。**

> **⚠ 72 ターンでは「0 件」に強い意味は無い**（3 対 0 の Fisher は有意にならない）。
> **意味があるのは機構のほうである** —— **648 ターンを通して崩れた字は `陽` だけだった**
> （[ADR-0029](0029-language-as-a-matched-bundle.md) の 16m）。**外せば起きない。**

### 3. **手順は1周で通った。ただし限界も見えた**

**§決定4 の手順は、書いたとおりに使えて、1周目で合格の組が出た。**

**⚠ 気になった点:**

- **`皮肉` の `0` の率が 86%** —— **失格の線（90%）のすぐ手前。**
  **72 ターンで非ゼロが 5 件しかない**ので、**この軸の割合（60%）にはほとんど意味が無い。**
  **`短気` と同じ形が、線の手前で起きている。**
  > **線を「90%」の1本にしたのは粗いかもしれない。**
  > **「非ゼロが N 件未満なら、割合を読まない」という別の目安が要る。**
- **窓が 36 ターン × 2 しか無い**ので、**振れ幅は当てにならない**（`皮肉` は 0 pt と出ている）。
  **手順の 60 ターンは「張り付きの判定」には足りるが、「振れ幅の判定」には足りない。**
